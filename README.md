# KittyWorld

Прототип офлайн-интерфейса для stand-alone игры: рогалик с анимэ-зомби, которого игрок собирает из найденных частей.

## Что уже сделано
- Приветственный экран с заглушками реквизитов:
  - Patreon: `ХХХХ-ХХХХ-ХХХХ-ХХХХ`
  - Boosty: `ХХХХ-ХХХХ-ХХХХ-ХХХХ`
- Экран **конструктора зомби** (head/torso/arms/legs).
- Подсчёт общей мощности сборки.
- Графический предпросмотр выбранных частей (SVG-карточки рендерятся локально, без сети).
- Вся логика локальная, без онлайн-функций.

## Быстрый запуск (Ubuntu)
1. Проверить Node.js (рекомендуется 18+):
   ```bash
   node -v
   ```
2. Запустить тесты:
   ```bash
   npm test
   ```
3. Поднять локальный сервер:
   ```bash
   npm run start
   ```
4. Открыть в браузере:
   - `http://localhost:4173`

## Наглядная проверка на Android
Ниже способ именно для локальной проверки интерфейса без публикации и без облака.

### Вариант A (через один Wi‑Fi)
1. На Ubuntu узнать локальный IP:
   ```bash
   hostname -I
   ```
2. На Ubuntu запустить сервер, доступный в сети:
   ```bash
   python3 -m http.server 4173 --bind 0.0.0.0
   ```
3. На телефоне (тот же Wi‑Fi) открыть браузер и перейти на:
   - `http://<IP_вашего_ПК>:4173`
4. Проверить сценарий:
   - На приветственном экране видны реквизиты Patreon/Boosty-заглушки.
   - Нажать «Начать сборку зомби».
   - Менять части в слотах и убедиться, что меняется «Общая мощь зомби» и графический предпросмотр ниже.

### Вариант B (USB, если нет общего Wi‑Fi)
1. Подключить Android по USB и включить USB debugging.
2. На Ubuntu сделать reverse-порт через adb:
   ```bash
   adb reverse tcp:4173 tcp:4173
   ```
3. На Ubuntu запустить:
   ```bash
   npm run start
   ```
4. На Android открыть в браузере:
   - `http://localhost:4173`

## Структура проекта
- `index.html` — разметка экранов.
- `src/main.js` — логика UI и рендер предпросмотра.
- `src/builder.js` — данные частей и функции сборки.
- `src/styles.css` — стили интерфейса.
- `test/builder.test.js` — автотесты на core-логику.
